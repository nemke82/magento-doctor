Core Philosophy

From Disconnected Warnings to Root Cause Forensics

Standard health checkers test isolated criteria without understanding how Magento subsystems interact. Magento Doctor builds an internal normalized model of the store and correlates facts across modules, database schema, and runtime.

Safety Blueprint

Production Safe. Zero Telemetry. Air-Gapped.

Running diagnostic tools against enterprise e-commerce environments requires strict non-intrusive safety principles.

Zero Secret Exposure

Passwords, crypt keys, Redis tokens, and API headers are never held as plain text in memory or stored in snapshots. The normalized model maps them strictly as SecretValue::Present or SecretValue::Missing.

Safe Read-Only Operations

Default collectors execute strictly non-locking, read-only queries against information_schema with short execution timeouts (5s). Potentially heavy commands require explicit opt-in flags.

100% Offline & Local

Zero phone-home telemetry. Zero external cloud dependencies. Zero AI API calls. All parsing and correlation occur locally on your machine in native compiled machine code.
